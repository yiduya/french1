# 教材内容处理规范

完整用户 PDF 为唯一教材主体，原文件不修改；登记名称、版本、大小、SHA-256、页数、可读性、文字层与附录状态。未收到文件不推断内容或版本。

所有内容明确标记以下来源类型：
- Textbook Content：原教材内容，有可核查定位。
- Additional Explanation：新增教学解释，不伪装原文。
- Extra Practice：新增题，与原题独立编号。
- Fun Fact — Additional：新增趣味知识，保留可靠参考。

原题保留章、练习、题号与题答关系；答案注明原书答案或新增参考答案。缺失、模糊、提取异常标记 needs_review，不自动补全。区分逐字转录与编辑后的说明，保留核对记录。不同合理翻译不以唯一字符串拒绝。

法语重音、撇号、连字符、跨页/多列/表格均需对照页面；物理页和印刷页不混用。Phase 1 才建立完整提取与覆盖清单。全书题目完整性最终以 PDF 清单核验，不能只验证现有 JSON 内部自洽。

词汇统一原形 ID，明确词形关联证据；词性、性别、复数、变位、翻译按类型检查。IPA 的来源、方言和人工校验状态需记录；自动生成不等于可靠，未核验不能宣称已验证。

新增解释与 UI 全部英文，学习文本法语配英文。助记无可靠依据可省略；Supporting/Optional 不默认增加必背负担。语法依赖先教后练，不泛化全部 -ir 动词。Fun Facts 贴近内容、短小、可听。

后续校验应覆盖 ID、引用、答案、词汇关键字段、翻译、可播法语片段、微课路径、原题覆盖、题答匹配；自动校验不能替代语言人工核对。版权教材仅个人使用，不公开发布或重新分发。
