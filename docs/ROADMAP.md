# 开发路线与阶段门禁

每阶段只执行获批范围；完成统一报告与 PROGRESS 更新后停止。当前 PHASE 0–3 已获确认；PHASE 4 已完成并等待确认；PHASE 5–11 未开始。

| 阶段 | 产物与验收重点 |
|---|---|
| 0 | 环境、输入文件、结构和规划；需真实 PDF 可读性/文字抽样及答案附录存在性检查，输入全部确认后才能通过 |
| 1 | 完整目录、教材结构/提取/质量报告、第 8 课初步提取；识别跨页、表格、法语字符、页眉页脚、扫描页及题答对应，保留来源定位 |
| 2 | 第 8 课完整微课教学设计；逐步目标、词汇分类、语法/例句/微练习、Fun Facts、原题分配和难度依赖；用户审查 |
| 3 | 统一设计系统与可运行原型：Dashboard、Course Overview、Lesson Map、词汇、语法、习题、Fun Fact、Review；真实已核验示例，桌面/手机检查；用户审查 UI |
| 4 | 结构化内容模型、读取与 schema 验证、来源关系，第 8 课部分真实数据；可复用、可调序、可查原题 |
| 5 | 第 8 课完整分组词汇及卡片、助记、自测、困难词、复习入口；短批次后即时练习 |
| 6 | 正常/慢速发音、语音设置、失败与中断处理、逐词释义及词形映射；真实设备验证 |
| 7 | Essential / Explanation / Deep Dive、变位、可播例句、常见错、微练习、关联 Fun Facts |
| 8 | 全部第 8 课原题与答案逐题核对，逐层提示、解释、自评/自动评分、重做、错题、Original Order |
| 9 | IndexedDB 进度、复习调度、历史、恢复、导入导出和迁移；刷新/关闭/更新/备份恢复验证 |
| 10 | 完整新生旅程；规格列出的 18 项检查及必要单元/组件/E2E；修复报告、风险和全书建议；必须明确批准后进入全书 |
| 11 | 按原章顺序每批 2–4 章提取→分类→依赖→微课→语法/助记/练习/Facts→答案→IPA→校验；每批报告，最终全书覆盖、去重、引用、性能、无障碍、备份和文档验收 |

Phase 0 收到 PDF 后仅做文件可读性、少量文字提取与答案/附录存在性检查；不统计全书题量、不制作目录、不提取第 8 课。这些属于获批后的 Phase 1。

测试随阶段引入：本阶段环境/初始化/输入状态；阶段 3 构建和视口/键盘；阶段 4 schema/关系；阶段 6 TTS 实机；阶段 8 评分与完整性；阶段 9 调度、迁移与恢复；阶段 10 完整旅程。不得把计划当作已通过测试。
