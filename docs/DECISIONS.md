# 架构决策

日期：2026-10-20（America/New_York）

- D001 — 采用用户指定 React + TypeScript + Vite + Tailwind CSS；静态客户端、无后端/登录/云库；Python + PyMuPDF 离线处理教材。前端依赖与锁文件在 PHASE 3 初始化，本阶段不安装无关包或制作网站。
- D002 — 复用 `/workspace/french1` 现有空 Git 仓库。当前仅文档、输入目录和环境检查脚本；未来结构与实际文件明确区分。
- D003 — IndexedDB 保存用户数据，课程独立版本化；稳定 ID 不依赖展示排序。迁移、备份格式、事务性导入和调度算法在 PHASE 4/9 细化验证，不提前实现。
- D004 — Web Speech API 首选，音频资产接口备用；系统语音质量和离线能力必须实测，不承诺一致。IPA 保留独立来源和校验状态。
- D005 — 教材/抽取内容/音频及用户备份默认忽略 Git。忽略规则只是防误提交措施；任何未来打包仍需检查，不将教材部署到公开站点。本阶段无 Sites 注册、同步或发布。
- D006 — 来源定位计划包含文件哈希、PDF 物理页（1-based）、印刷页码（可空）、区域/原题编号；缺失及不确定项保留 needs_review。正式 schema 属于 PHASE 4。
- D007 — 先设计和验收完整第 8 课，再扩展全书；所有后续阶段必须获得用户确认。PDF 缺失时 Phase 0 标记 blocked，不能宣称验收通过。
- D008 — 不额外引入状态管理或大型 UI 库；如后续确有需要先说明理由。精确依赖版本届时锁定，避免现在假报构建成功。

## PHASE 1 补充决策

- D009 — PDF 为文字与图片混合，采用双通道提取；不能把无文字页当空页。全书图表识别工件与人工转录分离，自动脚本不得覆盖人工核读文件。
- D010 — 完整课程范围含 50 课、10 组阶段复习和 R11 总复习，不丢弃复习中的 Fun Facts。目录原题名优先，主题简称仅作别名。
- D011 — 正文编号点号/连字符与答案中点仅在检索键归一化，显示来源保留原标签。全书组级匹配与小题级核对分别记录，计数不足不通过自动推断补造。
- D012 — 本阶段 artifacts 是来源工件，非正式课程 schema；印刷页码未知时为 null，保留 PDF 物理页与 bbox。图片题及全书小题计数明确 needs_review，第 8 课单独核读。

## PHASE 2 教学设计决策（2026-10-21）

- D013 — 第 8 课采用 17 个可分次学习的微课，12 个表内核心动词分 3/3/2/2/2 批；花卉及额外颜色词不自动成为必背新词。
- D014 — 原题按知识依赖拆分，不改题号；Original Order 与教学顺序共用题目身份。设计映射只作覆盖检查，不提前实现 PHASE 4 schema。
- D015 — 第 8 课可直接开始；Previously Learned 依实际用户历史而非章号。按需提供主语、être、ne…pas、连接词及代词指代桥接，不要求先学完整后续语法章。
- D016 — 真假题匹配显示教材预期，另注现实语境限制；开放翻译默认参考比较/自评，不以严格字符串判错。显示答案不等于掌握。

## PHASE 3（2026-10-21）

- D017 — 按既定 React/TypeScript/Vite/Tailwind 初始化，锁定依赖；Georgia/系统 sans 字体，无字体外链。Lucide 仅提供图标，避免大型 UI 库。
- D018 — 本地原型不发布，src/data/prototype.json 是来源样本而非正式 schema；完整模型留给 PHASE 4。五屏代表体验，不假装实现完整 17 微课。
- D019 — 为音频入口提供最小浏览器试播/失败反馈；无可用法语声音不回退其他语言。完整语音与 IPA 工作仍归 PHASE 6。
- D020 — 会话内预览状态不写浏览器数据库；明确刷新重置，避免误导长期进度。复习评分只演示交互，不启动调度。

## PHASE 4（2026-10-21）

- D021 — 使用 Zod 4 作为类型与 schema 单一来源，导出 JSON Schema；跨引用、原题覆盖及来源规则由 TS 验证器处理。增加 tsx 用于直接运行 TS 校验/测试，无服务端依赖。
- D022 — FrenchText 单独归一化，AudioAsset 双向绑定；内容和用户数据独立格式，词汇状态通过稳定 ID 关联，不将 Previously Learned 固化到内容。
- D023 — sample 漏题为 warning、complete 漏题为 error；strict 模式拒绝任何 warning。未核验 IPA 明确 null，保留审核状态，不自动补造。
- D024 — 正式内容加载为原子操作；错误不替换有效内容，查询返回副本。更新词条/调序不更换稳定 ID；本阶段不实现持久化或迁移。
- D025 — 私人 v1 样本仅 3 道题，对照独立全 34 题清单；公开 CI 使用合成数据，Pages 继续检查私人文件不存在。旧 UI fixture 保留，不能与正式内容格式混用。
